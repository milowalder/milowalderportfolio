# Milo Walder — Engineering Portfolio

This is a complete static website. No build step, package installation, API key, or ChatGPT connection is needed.

## Preview

Extract the ZIP and open index.html in a browser. Keep styles.css, navigation.js, the résumé PDF, and the assets folder beside it.

## Move to GitHub

Create a repository, then upload the contents of this folder to its root. index.html should be at the repository root, not inside another folder.

For GitHub Pages, select the main branch and root folder as the publishing source in the repository's Pages settings. Publishing availability depends on the repository visibility and GitHub plan. The exported site does not include the access restrictions of the ChatGPT-hosted version.

## Edit

- index.html: project descriptions, metadata, captions, and links.
- styles.css: typography, colors, spacing, and responsive layouts.
- navigation.js: immediate project selection and scrolling.
- assets/: photos, diagrams, logo, and locally bundled fonts.
- Milo-Walder-Resume.pdf: downloadable résumé.

All asset paths are relative, so the site works in a GitHub project subdirectory.
